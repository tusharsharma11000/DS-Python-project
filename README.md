🛒 Big Basket Product Analysis
📌 Overview

This project performs Exploratory Data Analysis (EDA) on the Big Basket dataset containing over 28,000 product records. The objective is to analyze product pricing, discounts, and category-wise trends to gain meaningful business insights.

🎯 Objectives
Analyze product pricing trends.
Identify discount patterns across categories.
Detect outliers in product prices.
Compare market price and sale price.
Generate insights using data visualization.
🛠️ Technologies Used

Matplotlib
Seaborn
Jupyter Notebook

🔍 Analysis Performed
Data Cleaning
Removed duplicate records.
Handled missing values.
Converted data into appropriate formats.
Exploratory Data Analysis (EDA)
Category-wise product distribution.
Price distribution analysis.
Discount percentage analysis.
Brand-wise product analysis.
Market Price vs Sale Price comparison.
Outlier Detection
Applied IQR (Interquartile Range) method.
Identified unusually high and low-priced products.
📈 Key Insights
Some product categories offer significantly higher discounts.
Premium products have distinct pricing patterns.
Discounts strongly influence product pricing.
Certain categories dominate the overall product inventory.
🚀 Results

The project provides valuable insights into pricing strategies, discount trends, and category performance that can help businesses make data-driven decisions.
